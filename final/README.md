# GreenTech Solutions Website

The project entails the development of an entirely responsive and accessible website that was made for a fictitious business enterprise called GreenTech Solutions that concentrates on eco-friendly technology and sustainability. This website was developed for the purpose of informing individuals about the problems faced by our environment and how sustainable technologies can be utilized to solve them.

The website consists of different pages that have the ability to be navigated from one page to another using navigation buttons.

## Live Site Link

GitHub Pages URL:

## Features

### HTML
- Semantic HTML5 structure
- Multiple pages:
  - Home
  - About
  - Products
  - Resources
  - Contact
- Navigation bar on every page
- Forms, tables, lists, headings, images, and paragraphs

### CSS
- External stylesheet (`final.css`)
- Responsive layouts
- Mobile-friendly design
- Hover effects and styling
- Consistent green and earth-tone color scheme

### JavaScript
- Contact form validation
- Newsletter signup validation
- Interactive hover animations on cards
- Dynamic success/error messages

### Mobile Responsiveness
- Responsive layouts using media queries
- Flexible navigation bar
- Mobile-friendly formatting and spacing
- Tested using browser device emulation tools

### Accessibility
- Alt text added to images
- Semantic HTML structure
- Readable font sizes and color contrast
- Labels included for all form fields

## Development Reflection

The project proved easier to accomplish than I initially thought it would be. One of the decisions I needed to make during the process was related to the creation of fake team members and the usage of stock photos on the About page. I did not follow that course of action since I opted for keeping the project simple and functional.

Moreover, I had to take care of the matter of adding, organizing, and creating a hover/pop-out effect on images using CSS and JavaScript. Although I spent a considerable amount of time looking for a proper way of accomplishing those tasks, I succeeded after a while due to the help provided by documentation.

Additionally, one of the problems I faced was related to the page header which did not display properly because of heading tags being placed within the "title" element. After finding a solution, I fixed the headers on all five pages.

Furthermore, there came the moment when I wondered whether I need to make navigation links work properly before I realized that it was mandatory in order to receive a good grade for the project. Once it was accomplished, the website gained in usability and completeness.

Overall, this project helped reinforce my understanding of HTML structure, CSS styling, responsive design, JavaScript interactivity, and accessibility practices.
